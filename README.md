iFinance Management System

**Overview**
iFinance Management System is a web-based financial management application designed to help users manage and monitor their financial activities efficiently. The system provides an interactive dashboard for tracking transactions, managing accounts, viewing financial summaries, and analyzing spending patterns through a modern and user-friendly interface.
** Features**
* Dashboard with financial overview and statistics
* Transaction management (Add, Edit, Delete)
* Income and expense tracking
* Search and filter transactions
* Financial summaries and reports
* Responsive user interface for desktop and mobile devices
* User profile management
* Local storage support for data persistence
**Technologies Used**
* HTML5
* CSS3
* JavaScript (ES6)
* Browser Local Storage
