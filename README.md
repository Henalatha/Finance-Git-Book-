# iFinance Management System

## Overview

iFinance Management System is a responsive web application designed to simplify finance and loan management. It provides an easy-to-use interface for managing customer finance records, EMI payments, payment history, and finance details. The project focuses on creating a clean, user-friendly dashboard using HTML, CSS, and JavaScript.

---

## Features

* Dashboard with quick navigation
* Finance List Management
* Add New Finance Records
* Customer Details Page
* EMI Payment Management
* EMI Reports
* Out Payments Tracking
* Receipt Management
* Responsive Design
* Search Functionality
* Modern User Interface
* Navigation between pages
* Client-side form validation using JavaScript

## Modules

### Dashboard

* Displays the main navigation.
* Provides quick access to all finance modules.

### Finance List

* Displays all customer finance records.
* Search customer information.
* Navigate to customer details.

### New Finance

* Add a new finance record.
* Enter customer, vehicle, and finance details.
* Validate required fields before submission.

### Customer Details

* View complete customer information.
* Display finance summary.
* Access payment-related modules.

### EMI Payment

* Record EMI payments.
* Automatically calculate totals where applicable.
* Validate payment amount.

### EMI Reports

* Display paid amount.
* Display pending balance.
* Display total balance.
* Show complete payment history.

### Out Payments

* Record additional expenses or payments related to finance.

### Receipt

* Generate and display payment receipts.

## How to Run the Project

1. Download or clone the repository.

```bash
git clone https://github.com/your-username/iFinance-Management-System.git
```

2. Open the project folder.

3. Open **index.html** in any modern web browser.

No installation or server setup is required.
